# Testing-Chords
Experimentally determining the probability of intersections between arbitrary chords of a circle. Used Jupyter Notebook.

Given two arbitrary chords in a circle, what is the probability that they intersect? As it turns out, this question is underspecified, since there are multiple ways to choose random chords in a circle. For example, we might produce a "random" chord by choosing two points on the circle and drawing the line between them (there is perhaps a problem if the two points overlap, but this edge case has measure 0 so we can ignore it). That method yields a probability of 1/3. We might also choose a random point within the circle, and then draw the unique chord with that point as its midpoint (we again encounter an edge case if the point is the center of the circle, but this event also has measure 0, so we can ignore it). This method yields a probability of 3/8. The purpose of this code is to demonstrate that by performing a monte carlo simulation.
